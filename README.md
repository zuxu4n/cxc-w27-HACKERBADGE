# CxC W27 Hacker Badge

Static HTML/CSS/JS. Requires Node.js; no install step.

```sh
npm run dev    # http://127.0.0.1:4173
npm run check  # syntax checks
```

- Edit and deploy `dist/`.
- Run `npm run build:qr` to rebuild the QR runtime from `vendor/qrbtf/`.
- Client-side only; badge details are not saved.
